# Полиуретан-цементные промышленные полы — проект

Производство полиуретан-цементных (PU-cement / уретан-цемент, в обиходе «Ucrete-тип») промышленных полов из компонентов европейского производства.

## Конфигурация проекта

| Параметр | Значение |
|---|---|
| Штаб-квартира (юрлицо) | Швейцария (вне ЕС / ЕЭЗ / таможенного и НДС-союза ЕС) |
| Производство (основная масса) | Дания (ЕС) — минерально-цементная часть + блендинг |
| Производство (жидкие компоненты) | Великобритания (после Brexit — третья страна для ЕС) |
| Склад-компоновка (kitting) и мировая отправка | ЕС — рекомендация: **Гамбург (DE)** |
| Рынки сбыта | Азия, Латинская Америка, США, Ближний Восток |
| Бизнес-модель | Asset-light: бренд + IP + контрактное производство (toll manufacturing) |
