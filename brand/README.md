### `icons/` — 6 товарных категорий
Единая сетка 48×48, штрих 2.1, только Strategic Gold: `oil-products`, `fertilizers`, `metals`, `gas`, `chemicals`, `solid-fuels`.

### `png/` — готовые экспорты
Прозрачный фон. Знак: 32–512 px; app-иконка: 32–512 px; лекапы: 1600 px.

### `tools/` — параметрический генератор знака
```bash
python3 tools/build_assets.py <выходная-папка>   # пересобрать весь комплект
```
Геометрия зафиксирована: силуэт 3:4 (150×200 ед.), уклон граней 2:3, штрих 22.5 ед., контрформа 24 ед., разрывы 14 ед., точная поворотная симметрия 180°. Для лекапов нужен шрифт Inter (OTF) в `tools/…` — путь указан в скрипте.

## Правила (из брендбука, действуют без изменений)

- Охранное поле = высота внутреннего просвета монограммы; минимальная ширина лекапа: 32 мм в печати, 140 px в digital.
- Для фольги и тиснения использовать **только плоскую** версию знака (не градиент).
- Не добавлять свечение, тени, 3D; не менять пропорции; не ставить на шумный фон.
- Золото ≤ 10–12% площади макета.
