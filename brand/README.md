### `icons/` — 6 товарных категорий
Единая сетка 48×48, штрих 2.1, только Strategic Gold: `oil-products`, `fertilizers`, `metals`, `gas`, `chemicals`, `solid-fuels`.

### `png/` — готовые экспорты
Прозрачный фон. Знак: 32–512 px; app-иконка: 16–512 px; горизонтальные блоки: 1600 px; вертикальные: 1120 px.

### `tools/` — параметрический генератор знака
```bash
pip install fonttools                            # нужен только для фирменных блоков
python3 tools/build_assets.py <выходная-папка>   # пересобирает SVG-комплект (logo/ + icons/)
```
Геометрия зафиксирована: силуэт 3:4 (150×200 ед.), уклон граней 2:3, штрих 22.5 ед., контрформа 24 ед., разрывы 14 ед., точная поворотная симметрия 180°.

Для фирменных блоков нужны `Inter-Bold.otf` и `Inter-SemiBold.otf` ([github.com/rsms/inter](https://github.com/rsms/inter)): положить в `tools/fonts/` или указать папку через `INTER_OTF_DIR`. Без шрифтов скрипт собирает знак, фавиконки и иконки, а блоки пропускает с предупреждением. PNG-экспорты собираются отдельно (рендер SVG в нужный размер, например headless-chromium с `--default-background-color=00000000`).

## Правила (из брендбука, действуют без изменений)

- Охранное поле = высота внутреннего просвета монограммы; минимальная ширина фирменного блока: 32 мм в печати, 140 px в digital. Дополнение по итогам стресс-теста: при ширине меньше ~220 px использовать компактную версию без подстрочника.
- На тёмно-синих поверхностях сайта использовать чистый знак `strateon-favicon.svg` — плашка app-иконки сливается с фоном того же цвета.
- Для фольги и тиснения использовать **только плоскую** версию знака (не градиент).
- Не добавлять свечение, тени, 3D; не менять пропорции; не ставить на шумный фон.
- Золото ≤ 10–12% площади макета.
