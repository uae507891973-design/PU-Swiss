## Замечания по использованию

1. **Адресность.** Письмо работает только именное: конкретному руководителю отдела продаж / трейдеру, с упоминанием его компании. Массовая безличная рассылка с вложением-PDF уходит в спам и портит домен strateon.pro.
2. **Выбор абзаца.** Из двух выделенных абзацев (завод/трейдер) в письме остаётся один.
3. **Вложение.** Прикладывать соответствующую языковую версию инфолиста (RU — для СНГ, EN — для остальных). Сканы документов директора не прикладывать — они передаются по запросу комплаенса (annex pack с водяными знаками).
4. **Конкретика.** Если на момент отправки есть реальный спрос (рынок, объём, базис) — назвать его в первом абзаце вместо общих слов: «есть подтверждённый интерес покупателя на [объём] [товар] [базис] [рынок]» — это удваивает отклик. Не называть того, чего нет.
5. **Фоллоу-ап.** Без ответа — одно короткое напоминание через 5–7 рабочих дней, затем пауза. Телефон/WhatsApp — после первого ответа либо если контакт получен по рекомендации.
6. **Комиссия.** Размер комиссии в первом письме не называть — это предмет встречи; фиксируется в агентском договоре по итогам.
