## 1. Бриф (зафиксированные решения владельца)

| Параметр | Решение |
|---|---|
| Архетип | **Инженер-эксперт**: точность, наука, испытания, холодная уверенность (код Sika/Hilti) |
| Языковой код | **Германский конструктив + английская читаемость + неологизм** (латынь/греческий — нет) |
| Гео-привязка | **Нет** (ни Swiss, ни Альпы в имени) |
| Охват | **Дом бренда**: одно имя на компанию и все продукты (как Sika → Sikafloor) |

### ⚠️ Юридическая рамка «Swissness» (причина отказа от гео)
Закон Швейцарии о «швейцарскости»: маркировать **товар** как «Swiss» можно только если ~60% себестоимости создаётся в Швейцарии (+ ключевая производственная стадия). Наше производство — Дания/UK → «Swiss» на продукте уязвимо. Для **названия юрлица** правила мягче, но бренд-нейм = маркетинг товара.
✅ **Решение:** имя без гео; «швейцарскость» доносим слоганом **«Swiss engineered. European made.»** — инжиниринг и правда в CH (IP, рецептуры, управление), производство честно «European».

## 2. Рекомендация: **DURWERK** (DURWERK AG)

### Семиотика — три уровня

**Уровень 1. Фоносемантика (звучание).**
- **D–R–W–R–K**: взрывной [d] + вибрант [r] + финальный смычный [k] — акустический профиль «твёрдости и завершённости». Имя «звучит как удар кельмы»: коротко, тяжело, без гласных «рыхлостей».
- 2 слога, 7 букв — глобальный оптимум запоминаемости (ср. HILTI, FESTO, KNAUF).

**Уровень 2. Морфология (корни и конструкция).**
- **DUR-** — считывается как «твёрдый/прочный» (durable, dur, duro) без прямого словарного заимствования → защитимо как неологизм. Бонус: в немецком **Dur** — мажорная тональность: «твёрдое, уверенное, утверждающее» звучание — красивая деталь для бренд-истории.
- **-WERK** — германский код «завод, творение, механизм» (Drägerwerk, Bosch-Werke, Urwerk). Несёт смысл «инженерное произведение», а не «краска в банке». Точное попадание в архетип инженера-эксперта.
- Конструкция = «завод твёрдости» / «фабрика прочности» — широкое поле: подходит любым полимерным системам, не заперто в «полы».

**Уровень 3. Культурные коды по рынкам.**

| Рынок | Как считывается | Риски |
|---|---|---|
| 🇦🇪 GCC | Германское звучание = немецкое машиностроение = высший инженерный статус; легко транслитерируется в арабский (دورويرك) | нет негативных значений |
| 🌏 Азия | Короткое, произносимо (ду-верк/дур-верк); «-werk» знаком по немецким брендам техники | нет |
| 🇺🇸 США | Читается «dur-work» — «durable work», интуитивно позитивно | нет |
| 🌎 ЛатАм | **duro** = «твёрдый, крепкий» по-испански/португальски — прямое попадание в УТП бесплатно | нет |
| 🇷🇺/СНГ | нейтрально-техническое | нет |
